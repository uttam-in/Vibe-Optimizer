# Vibe Optimizer - Product Overview

## What It Is
NLP-powered brand intelligence platform that analyzes sentiment and topics from multiple data sources (social media, reviews, support tickets).

## Core Capabilities
- Multi-source data ingestion (Twitter, Reddit, reviews, CSV)
- Sentiment analysis with intensity scoring (Positive/Negative/Neutral)
- Topic clustering and trend detection
- Real-time dashboard visualization
- Automated weekly email reports
- REST API for sentiment analysis

## Key Business Value
- Monitor brand perception across channels
- Identify emerging trends and risks
- Generate actionable insights from customer feedback
- Track sentiment changes over time

## Current Status
- Trained sentiment model (72.1% accuracy) in `models/`
- CSV ingestion fully functional
- API and dashboard components ready
- Social media adapters scaffolded (require API keys)
